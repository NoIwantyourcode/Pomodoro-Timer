# Welcome to the Pomodoro Timer website

This is a project that is designed to help me study effectively so I won't feel over worked or not prepare at all

# Features

1. Configurable time - you can change the time of your focus sessions and breaks as you want
2. Analog clock - The analog clock represents the current time and also visually represents how much time is remaining in your focus session
3. Light Mode and Dark Mode - You can change how the website looks to your preferences
4. Heatmap - this website tracks how many focus sessions you had in a day and represents it in a heatmap!

# Tech Stack

This website uses 3 different coding languages with different purposes, The main.html file is used to structure the website and create the visual elements. The style.css file is used to make those visual elements in main.html look good. The app.js file makes the entire website work and functions as the backend.

# How to contribute

1. clone this github repo
2. make the changes you want to make (You can implement visual changes in style.css, structure changes in main.html and backend/logic changes in app.js)
3. test the website to make sure you didn't break anything
4. submit a pull request here!
